# Original ROM files

- 0_b4-6_ic1038.bin = Monitor (in 1st 4k) and boot time routines (2nd 4k)
- 1_b4-3_ic1058.bin = BASIC 1
- 2_b4-3_ic1046.bin = BASIC 2
- 3_b4-3_ic1037.bin = BASIC 3
- 4_b4-0_ic1067.bin = Character generator

The component numbers in the PCBs, in documents and the file names above don't always match fully.
